# Estimator variants: ddof, skewness and kurtosis, recursion seeds, rounding to whole units, Student-t scale

The task description inside <task_instructions> takes priority over this card: where it gives a different formula, input, setting or convention, follow the task description.

Use this when a task computes standard deviations or z-scores, runs an exponential average or a variance recursion, sizes positions in whole units, or uses a Student-t distribution. A choice the task states always wins.

## Decisions

| Decision | Options | How the task text selects | When the text is silent |
|---|---|---|---|
| Divisor of a standard deviation | ddof=1 (sample, unbiased variance) or ddof=0 (population, maximum likelihood) | "sample", "unbiased", "ddof=1", or an inference statistic (t-statistic, standard error) mean ddof=1; "population", "ddof=0", or a normal maximum-likelihood fit mean ddof=0. | Depends on the quantity: a reported volatility or standard deviation of returns, a Sharpe ratio and an inference statistic use ddof=1 (sample); z-normalizing columns before a PCA (a correlation-matrix PCA) uses ddof=0, as sklearn StandardScaler and scipy.stats.zscore do; a moment inside a HAC (Newey-West) test statistic uses divisor $T$, consistent with that estimator's covariance. For other quantities defaults differ by library: pandas Series.std / DataFrame.std / cov use ddof=1, numpy std / var and scipy.stats.zscore use ddof=0, sklearn StandardScaler uses ddof=0; pick one deliberately and state it. Always pass ddof explicitly and use the same value for every series the task treats alike. |
| Skewness and kurtosis | biased sample moments ($g_1 = m_3/m_2^{3/2}$, excess $g_2 = m_4/m_2^2 - 3$) or bias-corrected ($G_1$, $G_2$); excess or raw kurtosis | A named function means its own defaults: `scipy.stats.skew(x)` is $g_1$ (`bias=True`), `scipy.stats.kurtosis(x)` is excess $g_2$ (`fisher=True`, `bias=True`); "unbiased" or "adjusted" means $G_1$, $G_2$ (`bias=False`, also what pandas `Series.skew()` and `Series.kurt()` return); "Pearson" or "raw" kurtosis means `fisher=False` (3 added). | Defaults differ by library: scipy gives the biased $g_1$, $g_2$; pandas gives the bias-corrected $G_1$, $G_2$. Call the function the task names, or pass `bias` explicitly, and use the same choice for every series. |
| Start of an exponential average (EMA) | first observation, `ewm(span, adjust=False)`; the simple mean of the first span values, starting at position span - 1; the weighted average with `adjust=True` | "seeded with the simple moving average" or "SMA seed" means the second; "recursive" or a formula with the previous value means the first; "pandas ewm" with defaults means the third. | The first-observation recursion, stated, with the warm-up values kept or dropped as the text says. |
| Start of a variance recursion (EWMA, GARCH) | sample variance of the whole series or of a first block; first squared return; backcast; zero | The text names it; a fitted GARCH from a library uses that library's backcast. | Sample variance of the estimation series, stated; the effect fades with the decay factor. |
| Start of a running quantity | a stated date's value (a signal day, an entry day), initial capital, or the first observation | The text says where a running peak, running total or high-water mark starts. | The first observation of the series the quantity is defined on. |
| Whole units | floor, round, or keep fractional | Buying with a cash budget uses floor (never exceed the budget); a count of names floor(q * n) differs from round(q * n); "round" means round. | Floor for shares or contracts bought with cash, then recompute the cash left; fractional only when the text allows fractional holdings. |
| Student-t scale | scipy `t(df, loc, scale)` has standard deviation scale * sqrt(df / (df - 2)); a standardized (unit-variance) t uses scale = sd * sqrt((df - 2) / df) | When the text gives a volatility for t innovations, decide whether it is the scale or the standard deviation; "standardized t" means unit variance. | Treat a stated volatility as the standard deviation and convert to scale, stated. |

## Check

1. Standard deviation: pandas `Series.std()` uses divisor $n-1$; NumPy `std` uses divisor $n$ unless `ddof=1` is given.
2. `scipy.stats.zscore` uses the population standard deviation (divisor $n$): $(x - \bar{x}) / s_{n}$.
3. Skewness: `scipy.stats.skew(x)` equals $g_1$; pandas `Series.skew()` equals $G_1 = g_1\sqrt{n(n-1)}/(n-2)$, which equals `scipy.stats.skew(x, bias=False)`; with a few hundred observations the two differ in the third decimal. Kurtosis likewise: `scipy.stats.kurtosis(x)` is excess $g_2$, pandas `Series.kurt()` is the bias-corrected excess $G_2$.
4. Exponential moving average with span $k$ has $\alpha = 2/(k+1)$. The recursive form `ewm(span=k, adjust=False)` starts at the first observation; the SMA-seeded form leaves the first $k-1$ values undefined, seeds with the mean of the first $k$ values, and continues $E_t = \alpha p_t + (1 - \alpha) E_{t-1}$. They differ early in the series.
5. Whole shares with a fixed fee: $\lfloor (\text{cash} - \text{fee}) / \text{price} \rfloor$, so that shares times price plus fee does not exceed the cash and one more share would.
6. Student t with $\nu$ degrees of freedom and a target standard deviation $\sigma$: the scale is $\sigma \sqrt{(\nu - 2)/\nu}$, because the variance of a t variable with scale $s$ is $s^2 \nu / (\nu - 2)$.
