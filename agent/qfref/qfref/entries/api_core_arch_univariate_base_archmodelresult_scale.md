# Official API description: arch.univariate.base.ARCHModelResult.scale (arch 8.0.0)

From the installed docstring, unchanged; sections other than the signature, summary and parameters are omitted.

```text
arch.univariate.base.ARCHModelResult.scale

The scale applied to the original data before estimating the model.

If scale=1.0, the the data have not been rescaled.  Otherwise, the
model parameters have been estimated on scale * y.
```
